Sistema de Emissão de Credenciais

Sistema web desenvolvido para automatizar a emissão de credenciais de estacionamento para idosos e pessoas com deficiência (PCD).

O sistema permite realizar o cadastro do beneficiário, gerar automaticamente a numeração da credencial, definir sua validade e gerar o documento em PDF para assinatura.

🛠️ Tecnologias
PHP
SQLite
HTML
CSS
JavaScript
FPDF / FPDI

Funcionalidades
Cadastro de beneficiários
Emissão de credenciais para idosos e PCD
Numeração automática
Controle de validade
Geração de credenciais em PDF
Sistema de login e controle de usuários
Fluxo de assinatura das credenciais

Sobre o projeto
Projeto desenvolvido durante minha formação em Sistemas de Informação, com foco em automação de processos e desenvolvimento de soluções para a administração pública.
